# Generators

These scripts generated the KiCad 10 schematic (`generator/schematic`) and placed, routed and checked the PCB (`generator/pcb`, using pcbnew's Python API and Freerouting). They were written for a specific build environment and contain absolute paths; they are published for reference and reproducibility, not as a polished tool. The KiCad project in `hardware/kicad` is the source of truth.
